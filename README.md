# EM Studio Beleza 💅

Site institucional do **EM Studio Beleza**, estúdio de nail design e beleza especializado em serviços profissionais de manicure, pedicure e tratamentos de unhas.

## 🎯 Sobre o Projeto

Site desenvolvido para apresentar os serviços oferecidos pela profissional **Ellen Moraes**, designer de unhas com mais de 3 anos de experiência. O site oferece uma experiência elegante e moderna para os clientes conhecerem os procedimentos disponíveis e entrarem em contato via WhatsApp.

## ✨ Funcionalidades

- 🏠 **Página Principal** com apresentação do estúdio
- 👤 **Seção Sobre** com foto e informações da profissional
- 💼 **Catálogo de Procedimentos** com cards interativos
- 📝 **Descrições Detalhadas** de cada serviço oferecido
- 📱 **Integração com WhatsApp** com mensagens personalizadas por serviço
- 📸 **Link para Instagram** da profissional
- 🎨 **Navegação Suave** entre seções com scroll animado
- 💳 **Métodos de Pagamento** e informações importantes
- 📍 **Seção de Endereço** e contato
- 🎨 **Design Responsivo** otimizado para mobile e desktop

## 🛠️ Tecnologias Utilizadas

- **React** 19.1.1 - Biblioteca JavaScript para construção da UI
- **TypeScript** - Superset JavaScript com tipagem estática
- **Vite** - Build tool e dev server
- **React Router DOM** 7.9.4 - Roteamento de páginas
- **TanStack React Query** 5.90.3 - Gerenciamento de estado e cache
- **Tailwind CSS** - Framework CSS utilitário
- **Lucide React** - Biblioteca de ícones
- **PostCSS** & **Autoprefixer** - Processamento de CSS

## 🚀 Como Executar

### Pré-requisitos

- Node.js (versão 16 ou superior)
- npm ou yarn

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/igorsantos314/em-studio-beleza-site.git
cd em-studio-beleza-site
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o projeto em modo de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
```
http://localhost:5173
```

### Build para Produção

```bash
npm run build
```

### Preview da Build

```bash
npm run preview
```

